# Назва Проєкту

Функціональний веб-проєкт, який демонструє мої навички роботи з SCSS, верстання респонсивних дизайнів та інтеграції динамічних елементів.

---

## 📱 Про проєкт
Цей проєкт — це адаптивна вебсторінка (Homepage), створена на основі дизайн-макетів для різних роздільних здатностей екрана: від мобільних пристроїв до Desktop HD (1920px).

### Реалізовані адаптивні версії (Брейкпоінти):
* **Desktop HD**: 1920px
* **Desktop**: 1440px
* **Tablet**: 768px
* **Mobile**: 370px / 420px

---

## 🚀 Технологічний стек
* **HTML5** — семантична розмітка.
* **CSS3 / SCSS** — стилізація, Flexbox, CSS Grid.
* **БЕМ (BEM)** — методологія іменування класів.
